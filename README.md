## نبذة عن المشروع

تطبيق To-Do List هو تطبيق هاتفي تم تصميمه خصيصاً لمساعدة المستخدمين على إدارة وتنظيم مهامهم اليومية بكفاءة وثبات عاليين. تم بناء هذا المشروع وفقاً لأفضل الممارسات البرمجية في تطوير تطبيقات الفلاتر، حيث يركز على فصل طبقات التطبيق تماماً، مما يضمن كوداً نظيفاً، قابلاً للتوسع، وسهل الصيانة والتطوير مستقبلاً.

## التقنيات المستخدمة

* Framework: Flutter (Dart)
* State Management: Flutter Bloc (Cubit) لإدارة الحالة بكفاءة تامة وفصل منطق الأعمال عن واجهة المستخدم.
* Local Database: SQLite لتوفير قاعدة بيانات محلية قوية وآمنة تضمن حفظ واسترجاع البيانات بسلاسة.
* Architecture Pattern: Clean Architecture (فصل الملفات إلى Cubit, Models, Views, Widgets, Database).

---

## المميزات والخصائص التقنية

* إدارة الحالة الذكية: متابعة التحديثات اللحظية على الشاشة وتغيير حالة المهام فوراً دون حدوث أي استهلاك زائد للموارد أو إعادة بناء غير مبررة للواجهات.
* التخزين المحلي الآمن: تكامل تام مع قواعد بيانات SQLite المحلية لضمان بقاء المهام محفوظة ودائمة الصلاحية حتى عند إغلاق التطبيق تماماً أو إعادة تشغيل الجهاز.
* إضافة وتعديل وحذف سلس: واجهات مرنة تتيح للمستخدم إضافة مهمة جديدة، تعديل حالتها، أو حذفها بضغطة زر واحدة.
* تجربة مستخدم مرنة: واجهات عصرية ونظيفة ومصممة بعناية لتوفير راحة بصرية وسهولة في التعامل.

## هيكلة فولدرات المشروع

تم تنظيم المشروع هندسياً داخل فولدر الـ lib لتسهيل تتبع الملفات والصيانة البرمجية:

```text
lib/
│
├── cubit/          # يحتوي على ملفات الـ Cubit والـ States الخاصة بإدارة الحالة
├── models/         # نماذج البيانات (Data Models) لهيكلة كائنات المهام
├── views/          # الشاشات الرئيسية والصفحات المرئية للتطبيق
├── widgets/        # المكونات الرسومية المتكررة والقابلة لإعادة الاستخدام
├── database/       # خدمات الاتصال والتهيئة وإدارة قاعدة بيانات SQLite
└── main.dart       # نقطة بداية تشغيل التطبيق وربط مزودات الحالة
